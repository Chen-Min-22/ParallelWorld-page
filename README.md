# ParallelWorld Project Page

Static project page for the ParallelWorld paper.

From this directory, start a local preview with:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173/>. Replace the `Authors · Affiliation` text,
the BibTeX block, and the main-results placeholder in `index.html` when the
final paper metadata and table are available.
